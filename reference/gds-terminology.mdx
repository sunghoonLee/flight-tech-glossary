## 1. 공통 기본 용어

### GDS (Global Distribution System)

항공, 호텔, 렌터카 등 여행 상품을 예약하는 **글로벌 유통 시스템**.

| GDS | 기반 | 비고 |
|-----|------|------|
| **Amadeus** | 유럽 (스페인 마드리드) | 글로벌 점유율 1위 |
| **Sabre** | 미국 (텍사스) | 북미 강세 |
| Travelport | 영국 | Galileo, Worldspan |

```
여행사 → GDS → 항공사/호텔/렌터카 → 예약 확정
```

### PNR (Passenger Name Record)

- 항공 예약 기록을 담는 **기본 데이터 단위**
- 승객 정보, 여정, 연락처, 발권 정보 등 포함
- 보통 6자리 영숫자 코드 (예: ABC123)
- Sabre, Amadeus 공통 개념

### BSP (Billing and Settlement Plan)

- IATA가 운영하는 **항공권 정산 시스템**
- 여행사와 항공사 간 대금 정산을 중개

```
고객 → 여행사 → 결제 처리 → BSP → 항공사
```

### 업체 식별 코드

| GDS | 용어 | 형식 | 예시 |
|-----|------|------|------|
| **Sabre** | PCC (Pseudo City Code) | 4자리 영숫자 | F8UM, 89AI, UX1K |
| **Amadeus** | OID (Office ID) | 9자리 영숫자 | SELK138J9 |

- 여행사/업체가 GDS 시스템에 접속할 때 사용하는 고유 식별 코드
- 회사의 "지점 번호"와 유사한 개념
- 채널별로 분리하면 트래킹/정산이 용이

```
Sabre:   PCC (Pseudo City Code)   예: F8UM
Amadeus: OID (Office ID)          예: SELK138J9
         └ SEL = 서울, K138J9 = 고유 식별
```

### 메타채널 (Meta Channel)

여러 항공사/여행사의 가격을 비교해주는 플랫폼. 직접 판매하지 않고 해당 여행사 사이트로 연결(리다이렉트).

| 메타채널 | 설명 |
|---------|------|
| **스카이스캐너** | 글로벌 항공권 비교 검색 |
| 카약 (Kayak) | 항공/호텔/렌터카 비교 |
| 구글 플라이트 | 구글의 항공편 검색 |
| 네이버 항공권 | 국내 메타검색 |

```
메타채널용 식별코드 분리 이유:
  - 메타채널에서 얼마나 유입되는지 정확히 측정
  - 채널별 수수료/정산 분리
  - 메타채널 ROI 분석 가능
```

## 2. 채널 분리

### Offline vs Online

| 구분 | Offline | Online |
|------|---------|--------|
| **처리 방식** | 상담원이 터미널에서 수동 처리 | API를 통한 자동 처리 |
| **접속 도구** | 데스크톱 예약 프로그램 | Webservice / API |
| **사용 채널** | 전화, 오프라인 상담 | 웹, 앱, 메타검색 |
| **Sabre** | Offline PCC + SR360 | Online PCC + Webservice |
| **Amadeus** | Offline OID + Sellconnect | Online OID + WSAP |

### 분리 목적

```
┌──────────────────┐    ┌──────────────────┐
│ Offline           │    │ Online            │
│ (PCC 또는 OID)    │    │ (PCC 또는 OID)    │
│                  │    │                  │
│ 상담원 수동 발권   │    │ API 자동 발권      │
│ 직접 예약 처리     │    │ 웹/앱/메타채널      │
│ 실적 트래킹        │    │ 실적 트래킹        │
│ 정산 분리          │    │ 정산 분리          │
└──────────────────┘    └──────────────────┘
→ 어느 채널에서 얼마나 팔렸는지 명확히 구분
→ 채널별 독립적인 정산 및 실적 관리
```

## 3. Sabre 용어

### 데스크톱 도구 / 환경 설정

#### SR360 (Sabre Red 360)

- Sabre의 **데스크톱 예약 에이전트 도구**
- 상담원이 사용하는 Sabre 터미널 프로그램
- Offline PCC에 이 설정이 필요

#### Cert Mode (Certification Mode)

- Sabre 시스템 연동 시 **테스트/인증 환경**
- 실제 예약이 아닌 테스트 목적으로 사용
- 운영 환경 전환 전 기능 검증 단계

```
F8UM (Offline PCC) + Cert Mode SR360 설정
→ 상담원이 SR360 프로그램으로 F8UM에 로그인하여 예약/발권
```

### API 연동

#### Sabre Webservice

- Sabre가 제공하는 **API** (프로그래밍 방식으로 연동)
- REST/SOAP API로 항공편 검색, 예약, 발권 등을 자동화
- Online PCC가 이 API를 통해 동작

```
웹/앱 → 서버 → Sabre Webservice API → 예약/발권
```

#### Credential (인증 정보)

Sabre Webservice 접속에 필요한 인증 정보들.

| 항목 | 정식 명칭 | 설명 |
|------|----------|------|
| **EPR** | Electronic Point of Reference | API 접속 시 사용하는 엔드포인트 식별자 |
| **Password** | - | API 인증용 비밀번호 |
| **Client-ID** | - | API 클라이언트 식별자. OAuth 등 인증 시 사용 |
| **endPoint** | - | API 호출 URL (예: `https://api.sabre.com/...`) |
| **pccEnc** | PCC Encrypted | 암호화된 PCC 값. 결제 모듈 등에서 보안 목적으로 사용 |
| **gscCode** | Global Service Code | Sabre 서비스 식별 코드 |
| **origin** | - | 요청 출발지/발신 식별자 |

### 모듈별 Credential

#### FareRule Module

항공 운임 규정을 조회하는 모듈. 항공권의 환불/변경 규정 등을 API로 조회.

| 필요 Credential | 설명 |
|----------------|------|
| endPoint | FareRule API 호출 URL |
| gscCode | Global Service Code, Sabre 서비스 식별 코드 |
| origin | 요청 출발지/발신 식별자 |

#### Payment Module

항공권 결제 처리 모듈. 예약 후 실제 결제(카드 승인 등)를 처리.

| 필요 Credential | 설명 |
|----------------|------|
| endPoint | Payment API 호출 URL |
| pccEnc | 암호화된 PCC (보안상 평문이 아닌 암호화된 값 사용) |

### Branch 설정

PCC 간의 **연결/접근 권한 설정**.

- Branch 설정이 되어 있으면: PCC A에서 PCC B의 예약 조회/수정 가능
- Branch 설정이 없으면: PCC A에서 PCC B의 예약에 접근 불가
- "지점 간 내선 전화 연결"과 유사한 개념

```
✅ 연결함:  F8UM (Offline) ↔ 신규 PCC (Online)
           → 서로 예약 조회/수정 가능 (같은 사업 범위)

❌ 연결 안 함: F8UM ↔ 89AI, UX1K
❌ 연결 안 함: 신규 PCC ↔ 89AI, UX1K
              → 기존 운영 채널과는 데이터 격리
```

## 4. Amadeus 용어

### 데스크톱 도구 / 환경 설정

#### Sellconnect

- Amadeus의 **데스크톱 예약 도구 연결 설정**
- 상담원이 Amadeus 터미널에 접속하기 위한 설정
- Sabre의 SR360에 대응

#### PDT Mode (Product Mode)

- Amadeus 시스템의 **운영 환경 모드**
- Sabre의 Cert Mode에 대응
- 실제 예약/발권이 가능한 프로덕션 환경

```
Offline OID + PDT Mode Sellconnect 설정
→ 상담원이 Amadeus 터미널에서 해당 OID로 접속하여 예약/발권
```

### 접근 권한 설정

#### EOS (Extended Office Setup)

- OID 간의 **연결/접근 권한을 설정**하는 기능
- Sabre의 Branch 설정에 대응
- 어떤 OID가 다른 OID의 예약을 조회/수정할 수 있는지 정의

#### AQO (Access Queue Office)

- OID 간 **큐(Queue) 접근 권한** 설정
- 다른 OID의 예약 큐를 조회/처리할 수 있도록 허용
- 큐: 예약 관련 메시지(일정 변경, 항공사 알림 등)가 쌓이는 대기열

```
Main Offline OID에 SELK138J9와 스카이스캐너 OID를 EOS/AQO 설정

┌──────────────────┐
│ Main Offline OID │
│ (신규 발급)        │
│                  │
│  EOS/AQO 연결:    │
│  ├─ SELK138J9    │  ← 기존 OID
│  └─ 스카이스캐너   │  ← 신규 Online OID
│     OID          │
└──────────────────┘
→ Main OID에서 두 OID의 예약/큐를 조회·관리 가능
```

### API 연동

#### WSAP (Web Services Access Point)

- Amadeus **웹서비스(API) 접속 포인트** 설정
- Sabre Webservice의 Credential 설정에 대응
- API를 통한 자동화 연동 시 필요

```
WSAP 설정 시 필요한 항목:
  - API 버전 정보
  - 인증 정보 (ID/PW)
  - 접속 엔드포인트 URL
  - 사용 가능한 서비스 목록
```

#### PNR_Split Service

- PNR(예약 기록)을 **분리**하는 서비스
- 하나의 예약에서 일부 승객/구간을 별도 PNR로 분리

```
PNR_Split 필요 사례:

원본 PNR (ABC123):
  승객: 홍길동, 김영희, 이철수, 박민수, 정수진
  구간: ICN → NRT (전원 동일)

변경 요청: 이철수, 박민수 일정 변경

Split 후:
  PNR ABC123: 홍길동, 김영희, 정수진 (기존 일정 유지)
  PNR DEF456: 이철수, 박민수 (새 일정)
```

- WSAP에 PNR_Split 서비스가 활성화되어 있는지 확인 필요

### 데이터 / 결제

#### DSR (Data Storage & Retrieval)

- Amadeus 시스템에서 발생하는 **예약/발권 데이터를 저장하고 조회**하는 시스템
- PNR, 발권, 정산 등의 데이터를 외부 저장소로 전달
- 데이터 분석, 정산, 리포팅에 사용
- SFTP, API 등의 방식으로 데이터 전달

```
기존:
  기존 OID → DSR → 저장소 A (기존 데이터와 혼합)

신규 (분리 후):
  신규 Offline OID → DSR → 저장소 B (별도 분리)
  신규 Online OID  → DSR → 저장소 B

→ 신규 채널의 데이터가 기존 데이터와 섞이지 않음
→ 채널별 독립적인 데이터 분석/정산 가능
```

#### PAS (Payment & Settlement)

- Amadeus의 **결제 및 정산 시스템**
- 항공권 결제 처리 (카드 승인, BSP 정산 등)
- Sabre의 Payment Module에 대응

```
결제 흐름:
  고객 → 여행사 → PAS (결제 처리) → BSP → 항공사

PAS 신청 시점:
  내재화 개발환경 시스템 구성 완료 후 신청 예정
  → 개발 인프라가 먼저 준비되어야 결제 모듈 연동 가능
```

## 5. Sabre vs Amadeus 용어 대응표

| 개념 | Sabre | Amadeus |
|------|-------|---------|
| 업체 식별 코드 | PCC (Pseudo City Code) | OID (Office ID) |
| 데스크톱 예약 도구 | SR360 (Sabre Red 360) | Sellconnect |
| 운영 환경 모드 | Cert Mode | PDT Mode |
| PCC/OID 간 접근 설정 | Branch | EOS (Extended Office Setup) |
| 큐 접근 권한 | - | AQO (Access Queue Office) |
| API 접속 포인트 | Sabre Webservice (EPR, Client-ID) | WSAP (Web Services Access Point) |
| 결제/정산 모듈 | Payment Module (pccEnc) | PAS (Payment & Settlement) |
| 운임 규정 조회 | FareRule Module (gscCode) | Fare Rules (API) |
| 데이터 저장/조회 | - | DSR (Data Storage & Retrieval) |
| 예약 기록 | PNR | PNR (동일) |
| 예약 분리 | - | PNR_Split Service |

## 6. 구조 요약

### Sabre 구조

```
┌─────────────────────────────────────────────────────┐
│                    Sabre GDS                         │
│                                                     │
│  기존 운영 (독립)          신규 (Branch 연결)          │
│  ┌──────┐ ┌──────┐      ┌──────┐    ┌──────┐       │
│  │ 89AI │ │ UX1K │      │ F8UM │←──→│ 신규  │       │
│  │(운영) │ │(운영) │      │(Off) │    │(On)  │       │
│  └──────┘ └──────┘      └──┬───┘    └──┬───┘       │
│     ❌ 연결 안 함            │          │            │
│                          SR360      Webservice      │
│                          상담원      API 자동화       │
│                                   ┌───┴────┐        │
│                                   │FareRule│        │
│                                   │Payment │        │
│                                   └────────┘        │
└─────────────────────────────────────────────────────┘
```

### Amadeus 구조

```
┌──────────────────────────────────────────────────────────┐
│                     Amadeus GDS                           │
│                                                          │
│  ┌─────────────────────────────────────────────┐         │
│  │         EOS/AQO 연결 (상호 접근 가능)         │         │
│  │                                             │         │
│  │  ┌──────────────┐    ┌──────────────────┐   │         │
│  │  │ Offline OID  │    │ Online OID       │   │         │
│  │  │ (Main, 신규)  │    │ (스카이스캐너,신규)│   │         │
│  │  └──────┬───────┘    └────────┬─────────┘   │         │
│  │         │                     │             │         │
│  │     Sellconnect            WSAP             │         │
│  │     (PDT Mode)          (API 연동)           │         │

│                                                          │
│  ┌───────────┐    ┌──────────┐                           │
│  │    DSR     │    │   PAS    │                           │
│  │ 데이터 저장  │    │ 결제/정산 │                           │

└──────────────────────────────────────────────────────────┘
```
